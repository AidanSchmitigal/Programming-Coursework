Description:

This program will draw fractal shapes using recursion.  The user will
be prompted to enter a number of levels for the fractal.  The program
will then draw a fractal shape based on the number of levels entered.
The fractal shape will be drawn using the Terminal and in the shape of
and X (see example below).

Instructions:

1) Compile the program with

make

2) Run the program with

make
or 
./Fractal

3) When you run the program it will ask you which fractal you would
   like to draw.  Enter the number of the fractal you would like to
   draw.

   Then some of the fractal have you enter a number of levels or
   other properties.

   All the fractals except for the last one will consume the Terminal
   forever and you will need to press Ctrl+C to exit the program.

4) Limitations:
- To exit the program you will need to press Ctrl+C on some of the
  fractals.
- Everything in the main file so it is a bit messy.
