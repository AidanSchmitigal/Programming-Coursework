    Use the "cout" keyword to print text to the console
    Enclose the text to be printed in quotes (" ") to indicate that it is a string
    Use "<<" to concatenate multiple strings or values together

    Example:

    \033[1;34mcout\033[0m << \033[1;32m"Hello, world!"\033[0m << \033[1;32mendl\033[0m; \033[2m// Prints "Hello, world!" to the console\033[0m
